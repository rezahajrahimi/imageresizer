# Image Resizer & Studio

یک نرم‌افزار سبک، مینیمال و کاربردی برای مدیریت و ویرایش تصاویر (تغییر سایز، برش، کاهش حجم و چرخش) نوشته شده با **Go** و **Fyne GUI**.

---

## قابلیت‌ها

- **فایل منیجر و کاوشگر پوشه (Folder Explorer):**
  - باز کردن یک پوشه کامل و لود آنی تمام تصاویر
  - دکمه بروزرسانی پوشه (Refresh) برای اسکن مجدد فایل‌های اضافه‌شده بدون نیاز به انتخاب دوباره پوشه
  - انتخاب تکی یا چندگانه فایل‌ها با دیالوگ سیستمی لینوکس (`zenity`)
  - جستجوی سریع و زنده بر اساس نام فایل
  - فیلتر بر اساس پسوند (`JPG`, `PNG`, `WebP`)
  - مرتب‌سازی (Sort) پیشرفته: بر اساس نام (A-Z / Z-A)، حجم فایل، و تاریخ ویرایش

- **پیش‌نمایش تعاملی و کراپ با ماوس (Interactive Crop):**
  - پیش‌نمایش آنی تصویر
  - درگ کردن با ماوس روی تصویر برای انتخاب محدوده برش
  - دکمه کراپ مربع ۱:۱ و امکان تنظیم دقیق پیکسلی

- **تغییر سایز (Resize):**
  - تغییر ابعاد دقیق با پیکسل
  - قفل خودکار نسبت ابعاد (Aspect Ratio)
  - کلیدهای سریع مقیاس: ۵۰٪، ۷۵٪ و ۱۰۰٪

- **تنظیم کیفیت و حجم خروجی:**
  - اسلایدر تنظیم کیفیت تصویر برای کاهش چشمگیر حجم در فرمت JPEG
  - پشتیبانی از ذخیره با فرمت‌های PNG و JPEG

- **ابزارهای چرخش و معکوس:**
  - چرخش ۹۰ درجه به چپ و راست
  - معکوس کردن افقی و عمودی (Flip H/V)

- **مدیریت ذخیره‌سازی:**
  - **Save:** ذخیره و بازنویسی مستقیم روی فایل اصلی
  - **Save As:** ذخیره با مسیر و نام دلخواه
  - **Batch Processing:** تغییر اندازه و فشرده‌سازی خودکار تمام تصاویر لیست و خروجی در یک پوشه مقصد

## نیازمندی‌ها

روی توزیع‌های دبیان/اوبونتو:
```bash
sudo apt update
sudo apt install -y golang gcc libgl1-mesa-dev xorg-dev zenity
```

---

## نحوه اجرا و ساخت (Build)

1. دریافت پکیج‌ها:
```bash
go mod tidy
```

2. اجرای مستقیم:
```bash
go run .
```

3. ساخت فایل اجرایی (Binary):
```bash
go build -o imageresizer main.go
./imageresizer
```
